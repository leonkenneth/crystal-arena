# Card terms → engine concept map

How printed card text and advanced-rule terms map to engine building blocks. Section numbers (§)
refer to **advanced rules v3.3**, effective 2026-08-07, which are not bundled here. Check the
current advanced rules on the official website before relying on a subtle ruling.

## Reading a card

A printed card has: **Element** (crystal color), **CP Cost**, **Type**, **Job**, **Category**,
**Power** (Forwards), the **generic-card icon** when applicable, and **abilities**. In the builder:

```
Element  → inferred from mana cost, or .Colors(...)      CP Cost → .Cost(n, "R") / .ManaCost("{2}{R}")
Type     → .Forward()/.Backup()/.Monster()/.Summon()     Job     → .Job("Warrior")
Category → .Category("VII")                               Power   → .Power(7000)
Abilities→ .TriggeredAbility / .ActivatedAbility / .Cast / .StaticAbility / .ContinuousEffect / .SimpleAbilities
```

## Core terms

| Card term | Meaning (rules §) | Engine mapping |
|---|---|---|
| **CP** (Crystal Points) | resource paid to cast (§5.2.1.2). At least 1 CP must match the card's Element. | Mana. Use numeric tokens for generic CP and element letters for colored CP; `.Cost(n,"R")`. `{Z}` is not CP. |
| **Crystal** | a separate resource generated by effects (§6.8). | Crystal-flavored mana represented by `{Z}`, for example `AddManaToPool("{Z}".Parse())`. |
| **Element** | Fire/Ice/Wind/Lightning/Water/Earth/Light/Dark (§5.2.1.1). | `CardColor` (Fire/Ice/Wind/Lightning/Water/Earth/Light/Dark). Mana letters: `{R}{I}{G}{P}{U}{Y}{W}{B}`. |
| **Field** | the play area; a card "on the field" (§7.7). | `Zone.Battlefield`. |
| **Break Zone** | discard/graveyard (§7.10). "Break" a card = field → Break Zone (§15.1.1.3). | `Zone.BreakZone`. |
| **Damage Zone** | a player's damage pile; 7 = loss (§7.8, §3.1.1). | `Zone.DamageZone`; `P.Life` in tests. |
| **removed from the game** | exile (§7.13). | `Zone.RemovedFromPlay`; effect `RemoveFromPlayTargets`. |
| **Active / Dull** | vertical vs. tapped (§6.3.1). "Dull" = tap. | `card.Tap()`, cost `new Tap()`, `{T}` in text. |
| **Freeze** | frozen cards don't un-dull next Untap (§15.2.4). | modifier `new Freeze()` (grants `Static.DoesNotUntap`, self-expires). Effects like `DullAndFreezeTargets`. |
| **Forward** | attacker/blocker unit with Power. | `.Forward()`. |
| **Backup** | support unit; taps for CP. | `.Backup()` (auto-gets `{T}: add CP` mana ability). |
| **Monster** | non-attacking unit. | `.Monster()`. |
| **Summon** | one-shot spell, resolves then → Break Zone. | `.Summon()` + `.Cast(p => ...)`. |
| **Character** | Forward + Backup + Monster collectively. | `card.Is().Character`; target with `trg.Is.Card(x => x.Is().Character)`. |
| **Job / Category** | trait tags (e.g. Job "Warrior", Category "VII"). | `.Job(...)` / `.Category(...)`; query `card.HasJob("...")`. |

## Ability types (§6.4, §11)

| Printed form | Kind | Builder |
|---|---|---|
| "When/Whenever …" | auto/triggered ability | `.TriggeredAbility(p => { p.Trigger(...); p.Effect = ...; })` |
| "{cost}: {effect}" | activated/action ability | `.ActivatedAbility(p => { p.Cost = ...; p.Effect = ...; })` |
| (Summon/spell body) | the resolve effect | `.Cast(p => { p.Effect = ...; })` |
| always-on stat/rule | field/static ability | `.SimpleAbilities(Static.X)` or `.StaticAbility(p => ...)` / `.ContinuousEffect(...)` |

## Special mechanics

- **EX Burst** (§6.5.2, §11.10): an optional effect applied when the card is revealed as damage.
  Mark the ability with `p.ExBurst()`. Shown as `{EX BURST}` in text (display only — never
  parsed as mana).
- **Damage N —** (e.g. "Damage 5 — …"): the ability is active only once its controller has taken ≥ N
  damage (§15.2.6; life ≤ 7−N in the engine). The current `.Damage(...)` helper drops its callback,
  so use `p.Condition = cond => cond.YouHaveLessThanXLife(7 - n)` on a `StaticAbility` until fixed.
- **Special ability `{S}`**: a powerful ability whose cost includes discarding a copy of the card
  (`{S}` glyph). Builder helper `.SpecialAbility(name, init, additionalCost?)`.
- **Limit Break** (§15.2.8): turn N face-down cards in the LB deck face up as an added cost.
  `.LimitBreak(level)` maps this to `RevealLimitBreakCards`; the engine zone is `Zone.LimitBreak`.
- **Generic-card icon / same-name field rule** (§5.2.2.1, §7.7.3): cards without the generic icon
  are limited to one same-name Character on the field; cards with it may coexist. The engine models
  this as `.Forward()`/`.Backup()`/`.Monster()` by default and `multiplayable: true` for the generic
  icon. Its internal "Legendary" type label is unrelated to Legend rarity (`L`). Test this behavior
  when relevant (see `Opus23_001C_Garland`).
- **Party / attacks** (§10): multiple Forwards attack together. In tests: `DeclareAttackers(f1, f2)`.
  Triggers: `WhenThisAttacks`, `WhenAForwardAttacks`, `AfterAttackersAreDeclared`.
- **"choose 1 …" / "up to 1 …"**: target requirements. Mandatory single → `AddEffect(...)` (Min=Max=1);
  "up to N" → configure `cfg => { cfg.MinCount = 0; cfg.MaxCount = N; }`. "opponent controls" →
  `ControlledBy.Opponent`; "you control" → `ControlledBy.SpellOwner`.
- **"you may …"**: an optional effect; in tests answer with `.Answer(true|false)`. Model with
  effects like `PayLifeThen`, `PayManaThen`, or a "may" wrapper.
- **"until the end of the turn"**: modifier initializer `{ UntilEot = true }`.
- **"search your deck for …"**: use `SearchMainDeckPutToZone`; inspect its current constructor and a
  nearby card because its argument list is extensive.

## Element ↔ mana letter cheat-sheet

`Fire={R}`, `Ice={I}`, `Wind={G}`, `Lightning={P}`, `Water={U}`, `Earth={Y}`, `Light={W}`, `Dark={B}`,
generic CP/Colorless=`{1}{2}…`, Crystal=`{Z}`. (See `Core/Mana/ManaParser.cs`.) `{T}`, `{S}`,
`{EX BURST}` are display glyphs only — represent them with `Tap`, the same-name discard target
created by `.SpecialAbility(...)`, and `p.ExBurst()`, respectively.

## When a ruling is subtle

Look up the section in the current advanced rules on the official website, e.g. controller changes (§6.2.6),
EX Burst timing (§6.5.2, §11.10), First Strike in a party (§15.2.3.4), Freeze (§15.2.4).
Card text beats rules on conflict (§2.1).
